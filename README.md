# MuseuM

Sistema de gerenciamento de Museu, desenvolvido como projeto pra disciplina de Engenharia de Software

+ M is for Manutenibility
+ U is for Usability
+ S is for Security
+ E is for Efficiency
+ U is for Understability
+ M is for Modularity

### Segue o passo-a-passo para executar a API

* Instale as dependências globalmente do TypeScript e, opcionalmente, do Yarn:

  ```powershell
  npm install --global typescript
  npm install --global yarn
  ```
* Após instalar, entre na pasta backend e execute, com `npm` ou no `yarn`:

  ```powershell
  npm install && npm run dev
  yarn install && yarn dev
  ```
* Caso não seja a primeira vez executando basta digita, com `npm` ou `yarn`:

  ```powershell
  npm run dev
  yarn dev
  ```
* Depois entre em [http://localhost:3030/](http://localhost:3030) e verifique se API está funcionando.
